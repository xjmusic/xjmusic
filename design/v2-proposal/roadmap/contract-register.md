# Contract register (names are fixed by the proposal; use them verbatim)

Spec writers MUST use these names. If a spec needs a name the proposal does not give, it must (a) follow the local convention shown here and (b) list it under "New names introduced" at the end of the spec so the consistency pass can reconcile duplicates.

## 1. Engine C ABI — `engine/include/xjmusic/xj_c.h` (04-engine §1), CMake target `xjmusic_c`, ABI version starts 1.0.0
Conventions: `extern "C"`; opaque handle `xj_engine*`; `xj_abi_version()` → semver triple; every function returns `xj_status`; results via out-pointers; strings UTF-8 with explicit length; engine owns returned buffers until next call on the same handle or `xj_free`; one handle per thread (`!Sync` in Rust); ids are 16-byte UUID byte arrays.
Functions (exact spellings): `xj_engine_create`, `xj_engine_destroy`, `xj_engine_load_project` (path or in-memory JSON), `xj_engine_start`, `xj_engine_finish`, `xj_engine_run_cycle(at_chain_micros, out_events, out_count)`, `xj_engine_set_control_mode`, `xj_engine_override_macro`, `xj_engine_override_memes`, `xj_engine_set_intensity_override`, `xj_engine_cue(const xj_cue*)`, `xj_engine_cancel_cue`, `xj_engine_earliest_landing(boundary, out_chain_micros)`, `xj_engine_set_tempo_policy`, `xj_engine_set_external_tempo`, `xj_engine_set_foundation_source`, `xj_engine_push_foundation_json`, `xj_engine_get_foundation_json`, `xj_engine_set_seed`, `xj_engine_get_seed`, `xj_engine_get_segments_json(from_micros, to_micros)`, `xj_engine_get_messages_json(since)`, `xj_engine_preview_cue_json(const xj_cue*)`, `xj_engine_get_template_config_json`, `xj_engine_get_meme_taxonomy_json`, `xj_engine_list_macro_programs_json`, `xj_free`.
Structs/enums: `xj_schedule_event` (fields exactly as 04-engine §1: type, instrument_type, instrument_mode, _pad, active_audio_id[16], instrument_audio_id[16], start_at_chain_micros, stop_at_chain_micros, from_volume, to_volume, release_millis, pitch_shift_semitones, stretch_ratio, waveform_key_offset); `xj_boundary` {XJ_BOUNDARY_NOW, _BEAT, _BAR, _SEGMENT, _MAIN, _MACRO}; `xj_cue_type` {XJ_CUE_MACRO, _MEMES, _INTENSITY, _CHORD, _ADVANCE, _HOLD, _LAYER_MUTE}; `xj_cue` (type, boundary, payload); `xj_status`; `xj_tempo_policy` {Content, External}; `xj_foundation_source` {Internal, External}.
Config additions: `TemplateConfig.commitHorizonBeats` (float), `TemplateConfig.followHoldMaxBars` (int), `InstrumentConfig.allowPitchShift` (bool), `InstrumentConfig.pitchShiftRange` (semitones), `InstrumentConfig.allowStretch` (bool); `InstrumentAudio.contentHash` (optional); entity `originPack`, `originVersion` (optional).
Craft stage added: `ExternalFoundationCraft` (runs in place of `MacroMainCraft` when foundation source is External).

## 2. Foundation record JSON (04-engine §3–4, 07-session §"The foundation record")
Top-level: `type:"foundation"`, `session`, `seq`, `segment{id, segmentType, beginBeat, beginChainMicros, totalBeats, barBeats, key, tempo, intensity, delta}`, `chords[{position,name}]`, `voicings[{chordPosition, instrumentType, notes}]`, `memes[]`, `foundationChoice{macro, main, mainOffset}`. Same JSON produced by `xj_engine_get_foundation_json` and consumed by `xj_engine_push_foundation_json` (engine side omits the `session`/`seq` envelope).

## 3. Rust workspace crates (03-architecture)
`xj-engine-sys` (bindgen over xj_c.h; build.rs drives cmake; static link), `xj-engine` (safe wrapper: `Engine` type, `run_cycle` → typed events, cues/overrides as methods, snapshots), `xj-dsp` (real-time audio graph), `xj-transport` (clock; `BeatClock` trait with `link` and `session` implementations behind feature flags), `xj-session`, `xj-control`, `xj-content`, `xj-station` (runtime + CLI: `play`, `render`, `capture`, `replay`), `xj-workstation` (desktop app).
Threads: audio callback (xj-dsp, never blocks), control (xj-station, 10–20 Hz tick), I/O (xj-content, xj-session), UI. Queues: SPSC ring (`rtrb`) for DSP commands; `arc-swap` (or triple buffer) snapshots for UI.
Time bases: chain time (µs), device time (sample frames), beat time (f64 beats, Link), wall time (ns monotonic). Only `xj-transport` converts.

## 4. DSP command set (05-workstation §"Command set")
`StartVoice{id, buffer, start_frame, stop_frame, gain_from, gain_to, release, bus}`, `UpdateVoice{id, stop_frame, gain_to}`, `StopVoice{id, release}`, `TriggerOneShot{buffer, frame, gain, bus}`, `SetBusGain`, `SetBusMute`, `SetBusSolo` {bus, value, ramp_frames}, `SetFxParam{bus, slot, param, value, ramp_frames}`, `SetMasterParams{…}`, `CaptureStart{path}`, `CaptureStop`. Every command carries an absolute device frame; late commands apply at next buffer boundary and are counted.
Buses: one per instrument type (Background, Bass, Drum, Hook, Pad, Percussion, Stab, Sticky, Stripe, Transition) allocated up front, plus Master. Insert FX per bus: state-variable filter, tempo-synced delay, short reverb, saturator. Master: look-ahead compressor (ratio retargeted per cycle, interpolated per frame), logarithmic DRC, high-pass, low-pass from TemplateConfig, no normalization, plus true-peak safety limiter. Voice pool default 256. Sinks: device (cpal), WAV capture (master and optionally per bus), null (offline), HLS later (archived design note).
Variants: pre-rendered stretched/shifted copies keyed by (content hash, stretch ratio, semitones), rendered on the I/O thread by xj-content; the audio thread never stretches.

## 5. Session protocol (07-session-protocol)
Discovery: mDNS `_xjsession._tcp`; join code (4 chars); QUIC (`quinn`) preferred, TCP fallback; length-prefixed JSON. Messages: `hello`, `welcome`, `reject`, `foundation`, `retract`, `claim`, `release`, `cue_request`, `cue_result`, `handoff_offer`, `handoff_accept`, `handoff_commit`, `presence`, `bye`. Epoch: (T₀ chain micros, B₀ beat, barBeats). Roles: Conductor, Follower. Effective commit horizon = conductor's horizon + every follower's dub-ahead. Failure table as in 07. Cue request policy default: accept all, sender shown; trust toggles; "ask" mode (Q13). Max 16 stations.

## 6. Performer input (08-performer-input)
Cues: Macro, Memes, Intensity(target, ramp beats), Chord(name, optional key), Advance, Hold, LayerMute(type, on/off). Gestures: OneShot, BusMute/Solo, BusGain, FxParam, Stutter, Fill. Moves: composed steps with relative timing (`at = "beat" | "bar" | "segment" | "bar+4"`). Mapping: TOML profile (`[profile]`, `[[map]]` with `input`, `cue`|`gesture`|`move`|`session`, `led`; `[moves.<name>].steps`). Sources: MIDI (`midir`), OSC (`rosc`), keyboard, gamepad (`gilrs`), on-screen. LED states: off, available, armed, active. Influence signals: control activity, room level (OSC), time in section; bias only, off by default.
Capture = seed + show lock + cue log (beat timestamps) + gesture log (frame timestamps) + bounced audio; replay reproduces chain and mix.

## 7. Commons (06-commons)
Pack layout: `<name>.xjpack/` with `pack.toml`, `README.md`, `content/libraries/**`, `content/templates/**`, `audio/<blake3>.<ext>`, `preview/render.ogg`. `pack.toml` tables: `[pack]` (name, version, title, authors, license SPDX, description, tags, engine, taxonomy), `[taxonomy] palettes`, `[dependencies]`, `[provenance] source`. Show: `show.toml` (`[show]` name, templates; `[packs]`; `[session]` taxonomy, commit_horizon_beats, follow_hold_max_bars) + `show.lock` (`[[pack]]` name, version, hash). Registry: index repo `xjmusic/commons` (static JSON `/index/<name>.json`), publishing = PR with CI (signature, lint, preview render, artifact upload), artifacts on Cloudflare R2 by content hash, mirrors, ed25519 (minisign-style) signing, offline mirror. CLI: `xj-content pack|lint|verify|publish|fetch --show|lock|render`. Licenses: CC BY 4.0 default, CC0 starter pack; `CREDITS.md` written into every capture, bounce, build, exported pack; contributor declaration. Taxonomy `xj-base@1`: NNNBPM, NNOTE, SMALL/MEDIUM/LARGE, BREAK/INTRO/OUTRO, character list (OPEN, WIDEOPEN, STRAIGHT, ROOTSY), grammar (!X, X!, $X, numeric). Lint rules as listed in 06 "The quality bar".

## 8. Workstation (05-workstation)
Modes: Play, Make, Ship. Performance surface elements: Scenes, Palettes, Intensity, Cue boundary, Harmony strip (commit-horizon line, "cue chord"), Layers (meter, mute/solo, claim indicator), Advance/Hold, Timeline, Capture. "Why" panel. Editors order: instrument+audio, template, program (bind, chord, event). Toolkit: Candidate A Tauri 2 + Svelte + Canvas/WebGPU vs Candidate B iced; surface is canvas-rendered either way; tie-breaker A. Ship mode: Build for engine (`build/*.wav` + project JSON as V1), bounce (offline render), capture export, Export pack. Platforms (Q10): macOS 12+ universal, Windows 10 21H2+ x64 (WASAPI; ASIO behind feature flag after countersignature), Linux glibc 2.35+ x86_64. Telemetry (Q11): none; opt-in crash reports (sentry SDK → GlitchTip/Sentry); local diagnostics bundle. Names (Q12): "XJ music workstation" v2; "XJ station"; "session"; "the Commons".
